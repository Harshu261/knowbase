# KnowBase

An AI-powered personal knowledge and study system.

## About

KnowBase is a personal knowledge platform designed to help users
store, search, understand, and revise their learning material.

The project is being built incrementally to explore:

- Backend engineering
- REST APIs
- PostgreSQL
- AI/ML
- Semantic search
- RAG
- LLM integration
- Docker
- Cloud deployment

## Current Status

🚧 Early development

Currently implemented:

- FastAPI backend
- Health check endpoint
- Document API
- PostgreSQL connection
- SQLAlchemy setup
